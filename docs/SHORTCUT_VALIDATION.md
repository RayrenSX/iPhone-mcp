# 手机系统动作真机测试

2026-10-10，通过本仓库新版 stdio MCP 的 `press_shortcut` 调用补充运行时，
在一台 USB 有线 iPhone / iOS 26.6.2 上测试。当前客户端还未刷新新工具目录，
因此动作测试使用新建立的真实 stdio MCP 会话；不是直接绕过 MCP 调用 HTTP。

每次操作均先读取状态和截图，获取控制租约，发送一次动作，再截图并在 finally
释放租约。所有九项动作均返回 `dispatched`，均完成租约释放。
返回值证明传输发送，不代表每项动作的 UI 效果已确认。

| 动作 | 结果 | 证据与边界 |
|---|---|---|
| `home` | 通过 | 从游戏返回主屏幕；也能关闭控制中心、App 切换器和 Siri |
| `app_switcher` | 通过 | 截图显示 App 卡片切换界面 |
| `control_center` | 通过 | 截图显示控制中心 |
| `siri` | 通过 | 截图显示 Siri 浮层 |
| `lock_screen` | 通过（人确认） | 用户确认实体手机已锁屏／熄灭；投屏保留锁屏前画面，截图不能单独证明锁屏 |
| `notification_center` | 未确认 UI 效果 | 分别从控制中心和主屏幕测试，未观察到通知中心打开；普通通知横幅不算通过 |
| `dock` | 未确认 UI 效果 | 主屏幕上调用后没有明确变化；未测试 iPad |
| `volume_down` | 未确认 UI 效果 | 从控制中心和主屏幕测试，未观察到明确的音量条变化或提示 |
| `volume_up` | 未确认 UI 效果 | 同上；截图细微差异不能证明音量变化 |

没有修改手机快捷键设置或合成 Windows 快捷键。未输入文本、提交 Siri 指令或
操作通知内容。测试结束时手机已锁屏，控制租约未占用。
本结果不覆盖 BLE、无线连接或其他 iOS 版本。

原始前后截图位于被 Git 忽略的 `artifacts/shortcut-live-tests/`，可能包含个人内容，
不随报告提交。
